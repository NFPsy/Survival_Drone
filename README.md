# 드론 지휘관 (가제)

드론을 지휘하는 사이버펑크 서바이벌 액션 게임 · 신입 게임기획 포트폴리오

> 이 문서는 Unity나 게임 개발을 잘 모르는 사람도 이해할 수 있도록, 어려운 용어가 나올 때마다 짧게 풀어서 설명합니다.

## 게임 소개

| 항목 | 내용 |
|---|---|
| 장르 | 생존 액션 (이동과 성장 중심의 서바이벌 액션) |
| 배경 | 사이버펑크·SF, 로봇이 도시를 장악한 근미래 |
| 그래픽 | 3D (쿼터뷰 시점 — 캐릭터를 비스듬히 위에서 내려다보는 각도. 예: 디아블로 같은 게임의 시점) |
| 플랫폼 | PC (itch.io 배포 예정 — itch.io는 인디 게임을 무료/저가로 올려 배포하는 사이트) |
| 개발 기간 | 1~2개월, 1인 개발 |
| 개발 환경 | Unity(게임을 만드는 프로그램) + Claude(AI 코딩 도우미), 3D 모델은 VARCO 3D 제작·에셋스토어 구매 병행, Blender(3D 모델 편집 프로그램)로 다듬음 |
| 형상 관리 | GitHub (코드 변경 이력을 저장하고 되돌릴 수 있게 관리하는 서비스) |

주인공은 로봇이 도시를 장악한 근미래 세계의 엔지니어다. 직접 싸우는 대신, 자신을 따라다니는 여러 대의 드론을 통해 싸운다. **플레이어는 이동만 담당**하고, 공격은 드론들이 자동으로 처리한다.

핵심 재미는 시간이 지나며 얻는 드론들을 **어떤 조합으로 키워나가는가**에 있다. 같은 시작이라도 어떤 드론을 먼저 얻고 어떻게 강화하는지에 따라 매판 다른 전략이 만들어지도록 설계했다.

## 조작법

| 입력 | 동작 |
|---|---|
| WASD / 방향키 / 게임패드 왼쪽 스틱 | 이동 |
| (없음) | 공격은 드론이 자동으로 수행 |

## 기본 진행 방식

- 한 판의 길이는 **8~10분**. 정해진 시간을 버티면 승리로 종료된다.
- 시간이 지날수록 로봇이 더 많이, 더 강하게 등장한다 (아래 "적 시스템" 표 참고).
- **XP**(경험치, Experience Point의 줄임말)를 모으면 **레벨업**한다. 로봇을 처치하면 그 자리에 XP 구슬이 떨어지고, 플레이어가 가까이 가면 자동으로 흡수된다. 레벨업할 때마다 3개 선택지 중 하나를 골라 드론을 늘리거나 강화하거나, 능력치를 올린다.
- 화면 위에는 항상 **HUD**(Head-Up Display — 체력/시간처럼 지금 상태를 알려주는 화면 표시)가 떠 있어서, 체력바·XP바·레벨·남은 시간을 바로 확인할 수 있다.

## 드론 시스템

드론은 최대 5~6개까지 동시에 보유할 수 있으며, 게임 시작 시 근접 드론 하나만 가지고 출발한다. 드론 하나는 5단계까지 강화할 수 있고, 5단계에 도달하면 상위 형태로 변신한다.

| 드론 | 역할 | 강화 시 좋아지는 것 |
|---|---|---|
| 근접 드론 | 주인공 주위를 돌며 가까운 적 공격 | 도는 속도 또는 크기 |
| 저격 드론 | 가장 가까이 있는 적을 원거리 공격 | 공격력 또는 공격 속도 |
| 폭발 드론 | 일정 시간마다 주변 전체에 범위 피해 | 폭발 범위 또는 피해량 |
| 회복 드론 | 주인공 체력을 서서히 회복 | 회복량 또는 회복 주기 |
| 수집 드론 | 아이템·경험치를 자동으로 끌어모음 | 끌어당기는 범위 |

## 적 시스템 — 폭주한 보안 로봇

| 로봇 종류 | 체력 | 이동 속도 | 부딪힐 때 피해 | 처음 등장 시점 |
|---|---|---|---|---|
| 약한 로봇 | 14 | 보통 | 6 | 시작부터 |
| 튼튼한 로봇 | 38 | 느림 | 10 | 1분 30초부터 |
| 빠른 로봇 | 8 | 빠름 | 6 | 1분 30초부터 |
| 강한 로봇 | 95 | 느림 | 18 | 6분째부터 |
| 보스 로봇 | 500 | 매우 느림 | 25 | 9분째, 한 번만 |

(위 수치는 난이도 "어려움" 기준이며, 쉬움/보통은 배율이 적용돼 더 낮다 — 자세한 내용은 아래 "난이도 시스템" 참고)

한 판을 세 구간(처음 3분 / 중간 3분 / 마지막 3~4분)으로 나누어, 로봇 등장 속도와 최대 동시 등장 수가 달라진다. (이렇게 시간에 따라 점점 어려워지게 짜놓은 것을 "난이도 곡선"이라고 부른다.)

## 프로젝트 구조

Unity 프로젝트는 보통 이런 폴더들로 이루어진다. 각각이 뭘 하는 폴더인지 처음 보면 낯설 수 있어서 간단히 설명을 붙였다.

```
Assets/                    (게임에 쓰이는 모든 것이 들어있는 폴더)
├── Scripts/               (게임 동작을 정의하는 C# 코드 파일들)
│   ├── Core/                게임 공용 시스템 (체력, 이벤트, 매치 타이머)
│   ├── Player/               플레이어 이동, 능력치, 경험치
│   ├── CameraControl/         쿼터뷰 카메라 추적
│   ├── Enemies/              적 데이터/AI(적 스스로 움직이고 공격하는 로직)/스폰(적을 생성하는 것)
│   ├── Drones/               드론 5종 + 드론을 관리하는 매니저
│   ├── Pickups/              XP 오브(구슬), 자석처럼 끌어당기는 범위
│   ├── LevelUp/              레벨업 3택1 선택지 UI
│   └── UI/                   HUD, 결과 화면, 메인 메뉴/설정
├── Data/Enemies/           적 5종의 수치(체력·속도 등)를 담은 데이터 파일
│                           (코드를 고치지 않고도 수치만 따로 바꿀 수 있게 분리해둔 것 —
│                            Unity에서는 이런 데이터 파일을 "ScriptableObject"라고 부른다)
├── Prefabs/                드론 3(+2)종, 적 5종, XP 오브의 "완성된 틀"
│                           (프리팹 = 미리 조립해둔 오브젝트 설계도. 하나 만들어두면
│                            게임 중에 필요할 때마다 똑같은 걸 계속 찍어낼 수 있다)
├── Models/                 실제 3D 모델 파일(fbx)과 그 텍스처(표면 이미지)·머티리얼
│   ├── Player/               주인공 모델
│   ├── Drones/               드론 5종 모델 (Melee/Sniper/Collector/Explosion/Heal 폴더로 분리)
│   └── Enemies/              적 5종 모델 (Weak/Tough/Fast/Strong/Boss 폴더로 분리)
│                           (같은 이름의 파일(diffuse.png 등)이 섞이지 않도록 종류별로 폴더를 나눠둠)
├── Materials/              오브젝트 표면 색/질감을 정하는 파일들 (일부는 여전히 단색 플레이스홀더)
└── Scenes/                 씬 = 하나의 "화면 세트" (예: 메뉴 화면, 실제 플레이 화면)
    ├── MainMenu.unity         시작 화면 (게임 시작/조작법/게임 설명/설정)
    └── InGame.unity           실제 플레이 씬 (예전 이름: SampleScene)
```

메인 메뉴에서 "게임 시작"을 누르면 **난이도 선택 팝업**(쉬움/보통/어려움)이 먼저 뜨고, 하나를 고르면 그 난이도로 `InGame` 씬이 시작된다. "조작법"/"게임 설명"은 같은 화면 위에 뜨는 팝업이고, "설정"에는 마스터 볼륨(사운드는 아직 없어서 지금은 효과 없음)과 전체화면 토글이 있으며 PlayerPrefs(설정값을 컴퓨터에 저장해두는 Unity 기능)에 저장되어 다음 실행에도 유지된다.

### 난이도 시스템

난이도는 **쉬움 / 보통 / 어려움** 3단계이며, 선택한 값은 PlayerPrefs에 저장돼서 다음 실행에도 유지된다(기본값은 보통). 지금까지 다듬어온 밸런스 수치(아래 "밸런스 조정 기록" 표)는 전부 **어려움 기준**이고, 쉬움/보통은 그 수치에 배율을 곱해서 낮추는 방식으로 구현했다 — 난이도별로 데이터를 3벌 따로 만들지 않고 "배율 하나"만 관리하면 되게 한 것이다.

적 스폰 속도·최대 마릿수는 난이도와 상관없이 항상 동일하다 — 쉬움/보통에서 적까지 덜 나오게 하면 XP 구슬을 모을 기회도 함께 줄어서 레벨업이 더 느려지는 역효과가 있었기 때문에, 난이도는 적의 체력·접촉 피해량만 낮추는 방식으로 조정한다.

| 난이도 | 적 체력·접촉 피해량 배율 |
|---|---|
| 쉬움 | 0.6배 |
| 보통 | 0.8배 |
| 어려움 | 1배 (원래 밸런스 그대로) |

## 개발 일정 및 진행 상황

기획서 기준 개발 일정표(총 7주 + 예비 1주)를 세워두고, 매주 정해진 목표를 하나씩 완료해나가는 방식으로 개발하고 있다.

- [x] 1주차 — 기본 뼈대 (이동, 카메라, 기본 적 이동)
- [x] 2주차 — 드론과 전투 골격 (드론 5종, 로봇 체력/피격/사망)
- [x] 3주차 — 성장 시스템 (경험치, 레벨업 3택1, 드론 5단계 강화·변신)
- [x] 4주차 — 난이도 곡선과 스폰 연결 (3구간 곡선, 로봇 5종, 승리 조건)
- [x] 5주차 — 밸런스 다듬기 *(1차 완료 — 조정 기록은 아래 표 참고, 추가 조정은 필요 시 이어서 진행)*
- [ ] 6주차 — 비주얼과 사운드 입히기 *(진행 중 — 실제 3D 모델 적용 완료, 드론 공격 이펙트/효과음 8종 연결 완료. 배경음악은 "듣기 거슬린다"는 피드백으로 완전히 꺼두고 파일도 삭제)*
- [ ] 7주차 — 마무리와 배포 준비 *(진행 중 — 타이틀/결과 화면 UI 마무리, 난이도 3단계, 일시정지 메뉴, 씬 이름 정리까지 완료)*
- [ ] 예비 주차 — 플레이 테스트, 포트폴리오 영상 촬영

모델 없이도 코드로 만들 수 있는 "게임 느낌" 작업:

- 피격 파티클 이펙트 (플레이어 + 적 5종, 맞았을 때 흰 스파크가 튀고 색이 잠깐 번쩍임)
- 저체력(체력 30% 이하) 화면 경고 연출 (화면 가장자리가 붉게 맥동)
- 레벨업/결과 화면 팝업 연출 (뚝 튀어나오지 않고 살짝 커지며 페이드인, 게임이 멈춘 상태에서도 정상 재생)
- `AudioManager`(사운드를 재생해주는 매니저) + 코드로 합성한 임시 효과음 6종(피격/사망/선택/레벨업/승리/패배) 연결 완료 — 실제 사운드 파일로 교체 예정
- 타이틀 화면·결과 화면 색상 테마를 게임 내 청록색(플레이어 색상) 계열로 통일
- 결과 화면에 "생존 시간 · 도달 레벨 · 보유 드론 수" 전적 표시 추가
- 쉬움/보통/어려움 3단계 난이도 시스템 (자세한 내용은 위 "난이도 시스템" 참고)
- 드론 4종(근접/저격/폭발/회복) 공격할 때 보이는 시각 이펙트 + 효과음 연결
- 일시정지 메뉴 추가 — 게임 중 P키를 누르면 "계속하기 / 재시작(현재 난이도 유지) / 메인메뉴" 3버튼이 뜨는 팝업
- `AudioManager`에 효과음 8종 추가 연결(드론 4종 공격음, UI 클릭, XP 획득, 보스 등장 경고, 저체력 경고) — 배경음악은 거슬린다는 피드백으로 완전히 꺼두고 파일도 삭제(효과음만 남음)

### 3D 모델 적용 현황

주인공, 드론 5종, 적 5종 — 총 11개 자리 전부 실제 3D 모델(폴리곤을 약 5,000개 수준으로 줄인 저용량 모델)로 교체 완료했다. 애니메이션은 없는 정지 포즈 모델이라 지금은 가만히 서 있는 자세로 움직인다.

- 빠른 로봇(Fast)만 구분을 위해 머리 위에 작은 하늘색 구슬 마커를 달아뒀다 (다른 로봇들은 원본 텍스처 그대로 유지)
- 남은 작업: 텍스처 파일 용량 최적화(PNG → 압축 포맷), 필요하면 애니메이션 추가

## 버그 수정 내역

**"버그"란** 개발자가 의도하지 않은, 프로그램이 잘못 동작하는 문제를 말한다. 밸런스 조정(수치를 일부러 바꾸는 것)과 달리, 버그는 "고쳐야만 하는 실수"라는 점이 다르다. 아래는 개발 중 실제로 발견하고 고친 버그들의 기록이다.
