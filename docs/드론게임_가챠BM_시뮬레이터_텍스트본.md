# 드론 지휘관 가챠 BM 시뮬레이터 — 텍스트 버전

> `드론게임_가챠BM_시뮬레이터.xlsx`를 Code 탭에서 읽을 수 있게 시트별로 옮긴 것. **값은 재계산된 결과**이고, 맨 아래에 핵심 수식을 따로 적었다. 수치의 원본 기준은 xlsx이며, 파란 글씨+노란 칸이 입력값이다.


## 시트: 사용법

- 행1:  | 드론 지휘관 — 가챠 BM 설계 시뮬레이터
- 행2:  | 재화 흐름 · 뽑기 확률 · 천장 · 잠금 리롤 · 과금 유형별 30일 성장을 한 파일에서 계산합니다.
- 행4:  | 시트 구성
- 행5:  | 요약 | 30일 결과와 핵심 설계 수치를 한 화면에서 확인합니다. 발표·포트폴리오에 바로 캡처해서 쓰는 시트입니다.
- 행6:  | 가정 | 모든 입력값이 모여 있는 유일한 시트입니다. 수치를 바꾸려면 여기서만 바꾸세요.
- 행7:  | 확률_천장 | SSR 기대 뽑기 수, 천장 효과, n회 뽑았을 때의 누적 확률과 차트를 보여줍니다.
- 행8:  | 잠금리롤 | 3슬롯 중 성공 슬롯을 잠그고 재뽑기하는 방식의 기대 비용을 프리미엄별로 비교합니다.
- 행9:  | 재화시뮬 | 무과금/소과금/고과금이 30일 동안 얻는 코어와 뽑기 횟수를 하루 단위로 계산합니다.
- 행11:  | 색상 규칙
- 행12:  | 파란 글씨 + 노란 칸 | 직접 수정하는 입력값 (가정 시트, 확률_천장/잠금리롤의 비교용 숫자)
- 행13:  | 초록 글씨 | 다른 시트에서 가져온 값 (수정하지 마세요)
- 행14:  | 검정 글씨 | 계산 수식 (수정하지 마세요)
- 행16:  | 사용 방법 (예시)
- 행17:  |  | 1) '가정' 시트에서 SSR 확률(D21)을 2.5%에서 3%로 바꾸고, 다른 등급 확률 합이 100%가 되게 조정합니다. (F22에 OK가 뜨면 정상)
- 행18:  |  | 2) '요약' 시트에서 SSR 1개 기대 비용과 무과금·소과금·고과금의 30일 기대 SSR 수가 어떻게 변하는지 확인합니다.
- 행19:  |  | 3) 판정이 '조정 필요'로 나오면 판당 코어, 천장, 확률 중 하나를 바꿔 '적정'이 될 때까지 반복합니다. 조정 이력은 README의 밸런스 조정 기록처럼 남겨두세요.
- 행20:  |  | 4) '잠금리롤'에서 프리미엄을 0%·50%·100%로 바꿔가며 소모량이 어떻게 달라지는지 보고 기본값을 정합니다.
- 행22:  | 가정과 한계 (반드시 읽어주세요)
- 행23:  |  | 모든 수치(확률 2.5%, 천장 70회, 코어 가격 10원, 월정액 등)는 시장 관행을 참고한 설계 초안용 가정입니다. 특정 게임의 실제 데이터나 사용자가 제공한 수치가 아닙니다.
- 행24:  |  | 기대 SSR 수는 '누적 뽑기 횟수 ÷ 천장 반영 기대 뽑기 수'로 근사한 값입니다. 실제 개별 플레이어의 결과는 운에 따라 크게 달라질 수 있습니다.
- 행25:  |  | 클리어율은 유형별 고정값이며, 뽑기로 강해져서 클리어율이 오르는 성장 피드백은 반영하지 않았습니다. CBT 로그 데이터로 이 부분을 보정할 수 있습니다.
- 행26:  |  | 결제는 실제 결제가 아니라 원화 → 코어 환산 계산만 합니다. 게임 내 확률·천장은 반드시 UI에 공개하는 방식으로 구현하세요 (국내 확률형 아이템 정보 공개 규제 대응).
